Core features & tech stack

Core Features
  • Real-time reset tracking for 330+ games
  • Multi-timezone support via IANA timezone database
  • JWT authentication with bcrypt + HMAC pepper
  • Full OpenAPI 3.0 / Swagger documentation
  • Anonymous tracking via localStorage — no account required
Tech Stack
  • Node.js 18 + Express + TypeScript
  • PostgreSQL — Docker locally, Heroku Postgres in prod
  • OpenAPI 3.0 / Swagger interactive docs
  • Heroku deployment, Vercel frontend
  • Role-based access control (User / Premium / Admin / Owner)
